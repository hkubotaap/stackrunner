# STACK RUNNER

N-BOX Custom(4WD)が側溝にはまった状態から、車に積んである道具だけで脱出する 3D 物理ゲーム(プロトタイプ)。

ブラウザで遊べます(Three.js + cannon-es。インストール不要)。

## 遊び方

左の2輪が、ぬかるんだ側溝に落ちた状態から始まります。4輪すべてがアスファルトに戻れば脱出成功です。

| 操作 | キー |
|---|---|
| 運転 | W/S 前進・後退、A/D ハンドル |
| フットブレーキ / サイドブレーキ | Shift(長押し) / Space(入・切) |
| タイヤ選択 | 1〜4 |
| スノーヘルパー / フロアマットを置く | Q / E(向きは F で切替) |
| 回収 | Backspace |
| ジャッキ | J 設置・撤去、Z 上げ、X 下げ |
| ロープ + 軽トラ | R 接続・解除、G 長押しで引いてもらう |
| VSA 切替 | V |
| ミュート | M |
| リセット | Esc |

難易度は画面下の「標準 / 高難度 / 鬼」で切り替えられます(既定は高難度)。

## 仕組み

- 車両は cannon-es のレイキャスト車両。車重 1,000kg、トレッド 1,295mm、ホイールベース 2,520mm、最低地上高 145mm、4WD。
- タイヤは真下の路面の摩擦で駆動力が決まります(ぬかるみ / 草地 / アスファルト / スノーヘルパー / フロアマット)。
- デフは弱いほうの輪が車軸全体を制限します(トルクバイアスあり)。浮いたタイヤにはトルクが乗りません。
- 泥で空転するとタイヤが掘れて沈み、グリップが落ちます。
- VSA が空転を検知すると出力をカットします。切るかどうかの判断がポイントです。
- 音はすべて Web Audio でリアルタイムに合成しています(音声ファイルなし)。

## ローカルで動かす

```
npm start        # http://localhost:8080
npm test         # ヘッドレスの物理テスト(要 npm install)
```

`vendor/` に three と cannon-es を同梱しているので、静的ホスティング(GitHub Pages など)でそのまま動きます。

## 既知の制約

- 実車のスペックは販売サイトの値で、ホンダ公式の諸元表では確認できていません。
- 前後重量配分と 4WD カップリングの配分比は仮定です。
- 地面そのものの変形(わだち、土の盛り上がり)は未実装です。タイヤごとの「掘れ」の数値のみ。
- 難易度バランスは、スクリプトによる操作の検証であり、人が遊んだ検証は十分ではありません。
