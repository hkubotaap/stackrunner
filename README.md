# STACK RUNNER

N-BOX Custom(4WD)が側溝にはまった状態から、車に積んである道具だけで脱出する 3D 物理ゲーム(プロトタイプ)。

ブラウザで遊べます(Three.js + cannon-es。インストール不要)。

## 車種

画面下の「車種」で切り替えられます。マップとルールは同じで、車の物理と見た目だけが変わります。

| 車種 | 色 | 車重 | 駆動 | エンジン |
|---|---|---|---|---|
| N-BOX Custom 4WD | 青 | 1,000kg | 前輪寄りのフルタイム4WD | 658cc ターボ 64ps、CVT |
| インプレッサ スポーツワゴン 2.0 AWD(GG系) | シルバー | 1,330kg | シンメトリカルAWD(センターデフ + LSD) | EJ20 NA 155ps/196N·m、5MT |
| ハスラー HYBRID X 4WD(MR52S) | 黄(ルーフ白) | 850kg | 前輪寄りのオンデマンド4WD | 658cc NA 49ps/58N·m、CVT |

インプレッサは、グレードを goo-net の TA-GG9(2003年、2.0L NA・5MT)の値で作っています。最低地上高(150mm)と前後重量配分(前58:後42)は資料が見つからず、仮定です。顔つきは2002〜2005年の「涙目」を模していますが、意匠は記憶に基づくもので、資料での確認はしていません。

ハスラーの寸法(3395×1475×1680、ホイールベース2460、165/60R15)は記憶に基づく値で、資料での確認はしていません。車重850kg、前後重量配分(前56:後44)、最低地上高180mm、トレッド、CVTの変速比(駆動力2600Nの算出に使用)、4WDの駆動配分は仮定です。サスペンションのばね定数(20、他の車は28)は、28だと軽い車体がジャッキの上で跳ねたため試行で決めた値で、実車の値ではありません。顔つき・配色(黄の車体に白いルーフ)も記憶に基づく意匠です。横滑り防止・トラクションコントロールは車ごとに有無と名称が違います。N-BOX は「VSA」、ハスラーは「ESP」で、どちらも空転を検知すると出力を30%に絞ります(V キーで切替、動作は同じ簡易モデル)。インプレッサ(2003年・2.0L NA)は装置が付いていない前提で、ボタンは「横滑り防止なし」の表示で押せず、出力は絞られません。この有無と名称は記憶に基づくもので、資料での確認はしていません。標準難易度では、道具なしでも抜け出せるゆすり方が1通り見つかっています(N-BOXでは見つかっていません)。

どの車も、溝にはまった状態からは道具なしでほぼ抜け出せません(解けない難易度でも構わない設計です)。

## ステージ

画面下の「ステージ」で切り替えます(既定は側溝)。

| ステージ | 状況 | 脱出条件 |
|---|---|---|
| 側溝 | 左の2輪が、ぬかるんだ側溝に落ちている | 4輪すべてアスファルトに戻る |
| 冬道 | 圧雪路の脇、除雪でできた雪山(路肩側)と吹きだまりにはまっている | 4輪すべて圧雪路に戻る |

冬道では、路肩の雪は0.5m四方の区画に分かれていて、**スコップ**で掘って低くできます。

- スコップボタン(または `C`)を選び、掘りたい場所をクリック/タップ。ふかふかの新雪なら1回で約12cm、約0.5秒です。**雪が締まっているほど、1回で削れる量が減り(密度に反比例)、振りも遅くなります**。氷は新雪の5分の1(約2.4cm)ずつしか削れません。掘った雪は捨てられます。
- 掘れるのは、タイヤから約2.4m以内。**タイヤが乗っている区画**と、**道具が載っている区画**は掘れません。
- 道路ぎわの雪山(除雪で締まっている)は車体の腹に当たるので、タイヤの通り道の雪山を、吹きだまりと同じ高さまで掘り下げます。掘りすぎて深い溝にすると、タイヤが浮いて腹が引っかかります。

### 雪の変化(冬道)

雪の区画は、重さ(単位面積あたりの雪の量)と**密度**(新雪100〜200、除雪された雪山は約260、圧雪約450、氷917 kg/m³)を持ちます。雪の量は保存され、高さは「量÷密度」です。次のことが起きます。

- **踏み固め:** タイヤや車体が載ると密度が上がり、高さが下がります(沈み込み)。荷重だけでは、新雪は230〜290kg/m³程度までしか締まりません。**空転するとずっと速く締まります**(せん断による圧密)。新雪が圧雪になる(約10秒の空転で摩擦が0.14→0.4前後)と、いったんグリップが出ます。
- **氷化:** 締まった雪の上でさらに空転すると、表面が磨かれて氷になります(約30〜40秒の空転で密度が800前後、摩擦0.1前後)。密度が高すぎる氷は滑ります。
- **腹ばい:** 車体の底が雪山に乗ると、その区画に荷重がかかって締まります。沈んだ車体が雪山に腹をつくと、その区画が車重で締まります。
- **押されて壁:** 車体が横から雪山に押し込むと、押す力が区画の破壊強度(密度の2乗と高さに比例)を超えたとき、雪が隣の区画へ押し出されます。押された雪は圧縮され、盛り上がって密度が上がります(最大高さ1.2m)。密度が高いほど押せなくなり、壁になります。ポケットの外の固い雪の壁には押し出せません。押す力は車の駆動力(タイヤのグリップで頭打ち)で決まるので、締まった雪山は、N-BOX やハスラーの力では押し出せませんでした(スクリプトでの確認)。自分のタイヤが前の区画を踏み固めて、押せなくしてしまうこともあります。

- 吹きだまり(新雪)は泥より少し滑りにくい程度(μ0.14〜0.2)で、空転すると掘れて沈みます。締まるにつれて掘れ込みは止まります。
- スコップは道具の数に限りはなく、側溝ステージでは使えません。


左の2輪が、ぬかるんだ側溝に落ちた状態から始まります。4輪すべてがアスファルトに戻れば脱出成功です。

| 操作 | キー |
|---|---|
| 運転 | W/S 前進・後退、A/D ハンドル |
| フットブレーキ / サイドブレーキ | Shift(長押し) / Space(入・切) |
| タイヤ選択 | 1〜4 |
| スノーヘルパー / フロアマットを置く | 道具ボタンで選び、地面をクリック/タップ(プレビューは置ければ緑、置けなければ赤)。キーなら Q / E(向きは F で切替) |
| タイヤ選択 | タイヤ付近をクリック/タップ |
| ジャッキ | ジャッキボタンを押してタイヤをクリック/タップ(キー J でも可) |
| スコップ | スコップボタンで選び、雪をクリック/タップ(キー C は選択タイヤの向き指定で掘る) |
| 回収 | Backspace |
| ジャッキ | J 設置・撤去、Z 上げ、X 下げ |
| ロープ + 軽トラ | R 接続・解除、G 長押しで引いてもらう |
| VSA 切替 | V |
| ミュート | M |
| リセット | Esc |

### 道具のルール

- スノーヘルパーは、**浮いている(接地していない)タイヤの真下**にしか挟めません。ジャッキで持ち上げてから挟みます。タイヤの前後・斜め・内側(進路)には、接地していても置けます。
- フロアマットは、**浮いているかどうかに関わらず、タイヤの真下には敷けません**。進路には置けます。
- ジャッキの下敷き(沈み込み防止)には、ジャッキの根元から約0.5m以内の道具が使えます。
- **回収**(Backspace / 回収ボタン): タイヤが乗っている道具、上に別の道具が重なっている道具は抜けません。タイヤを浮かせるか動かしてから回収します。抜けるものがあれば、最後に置いたものから回収します。
- 道具が届くのはタイヤから約2.4mまでです。

タッチ端末では画面に運転用のボタン(ハンドル、前進、後退、ブレーキ)が出ます。

難易度は画面下の「標準 / 高難度 / 鬼」で切り替えられます(既定は高難度)。

## 仕組み

- 車両は cannon-es のレイキャスト車両。車重 1,000kg、トレッド 1,295mm、ホイールベース 2,520mm、最低地上高 145mm、4WD。
- タイヤは真下の路面の摩擦で駆動力が決まります(ぬかるみ / 草地 / アスファルト / スノーヘルパー / フロアマット)。
- デフは弱いほうの輪が車軸全体を制限します(トルクバイアスあり)。浮いたタイヤにはトルクが乗りません。
- 泥で空転するとタイヤが掘れて沈み、グリップが落ちます。
- VSA が空転を検知すると出力をカットします。切るかどうかの判断がポイントです。
- 音はすべて Web Audio でリアルタイムに合成しています(音声ファイルなし)。

## ローカルで動かす

```
npm start        # http://localhost:8080
npm test         # ヘッドレスの物理テスト(要 npm install)
```

`vendor/` に three と cannon-es を同梱しているので、静的ホスティング(GitHub Pages など)でそのまま動きます。

## 既知の制約

- 実車のスペックは販売サイトの値で、ホンダ公式の諸元表では確認できていません。
- 前後重量配分と 4WD カップリングの配分比は仮定です。
- 地面そのものの変形(わだち、土の盛り上がり)は未実装です。タイヤごとの「掘れ」の数値のみ。冬道の雪は、0.5m四方の区画ごとの密度と高さだけを持つ簡易モデルです。雪の層構造、融解と再凍結、水分、粒の結合の時間変化、雪が区画をまたいで連続的に流れる挙動、タイヤ幅より細かい圧密分布は扱っていません。
- 冬道の路面の摩擦係数(圧雪路0.42、密度と摩擦の対応表、氷の0.08〜0.16など)、圧密の速さ、破壊強度、削れる量の式の数値は、ゲーム用に決めた値で、実測値ではありません。傾向(新雪<圧雪>氷、締まるほど掘りにくい、荷重で沈む)を再現するための調整値です。
- 冬道の脱出手順は、スクリプトで確認した1例だけです(雪山を高さ0.22mまで掘る。範囲は標準が車の前後7列、高難度と鬼が9列。約47〜61回のスコップ、ゲーム内で約30〜45秒)。人が遊んだ検証ではありません。
- 難易度バランスは、スクリプトによる操作の検証であり、人が遊んだ検証は十分ではありません。
