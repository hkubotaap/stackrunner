# STACK RUNNER

N-BOX Custom(4WD)が側溝にはまった状態から、車に積んである道具だけで脱出する 3D 物理ゲーム(プロトタイプ)。

ブラウザで遊べます(Three.js + cannon-es。インストール不要)。

## 車種

画面下の「車種」で切り替えられます。マップとルールは同じで、車の物理と見た目だけが変わります。

| 車種 | 色 | 車重 | 駆動 | エンジン |
|---|---|---|---|---|
| N-BOX Custom 4WD | 青 | 1,000kg | 前輪寄りのフルタイム4WD | 658cc ターボ 64ps、CVT |
| インプレッサ スポーツワゴン 2.0 AWD(GG系) | シルバー | 1,330kg | シンメトリカルAWD(センターデフ + LSD) | EJ20 NA 155ps/196N·m、5MT |

インプレッサは、グレードを goo-net の TA-GG9(2003年、2.0L NA・5MT)の値で作っています。最低地上高(150mm)と前後重量配分(前58:後42)は資料が見つからず、仮定です。顔つきは2002〜2005年の「涙目」を模していますが、意匠は記憶に基づくもので、資料での確認はしていません。

どちらの車も、溝にはまった状態からは道具なしでほぼ抜け出せません(解けない難易度でも構わない設計です)。

## ステージ

画面下の「ステージ」で切り替えます(既定は側溝)。

| ステージ | 状況 | 脱出条件 |
|---|---|---|
| 側溝 | 左の2輪が、ぬかるんだ側溝に落ちている | 4輪すべてアスファルトに戻る |
| 冬道 | 圧雪路の脇、除雪でできた雪山(路肩側)と吹きだまりにはまっている | 4輪すべて圧雪路に戻る |

冬道では、路肩の雪は0.5m四方の区画に分かれていて、**スコップ**で掘って低くできます。

- スコップボタン(または `C`)を選び、掘りたい場所をクリック/タップ。1回で約12cm、約0.5秒かかります。
- 掘れるのは、タイヤから約2.4m以内。**タイヤが乗っている区画**と、**道具が載っている区画**は掘れません。
- 道路ぎわの雪山は車体の腹に当たるので、タイヤの通り道の雪山を、吹きだまりと同じ高さまで掘り下げます。掘りすぎて深い溝にすると、タイヤが浮いて腹が引っかかります。
- 吹きだまりは泥より少し滑りにくい程度(μ0.14〜0.17)で、空転すると掘れて沈みます。
- スコップは道具の数に限りはなく、側溝ステージでは使えません。


左の2輪が、ぬかるんだ側溝に落ちた状態から始まります。4輪すべてがアスファルトに戻れば脱出成功です。

| 操作 | キー |
|---|---|
| 運転 | W/S 前進・後退、A/D ハンドル |
| フットブレーキ / サイドブレーキ | Shift(長押し) / Space(入・切) |
| タイヤ選択 | 1〜4 |
| スノーヘルパー / フロアマットを置く | 道具ボタンで選び、地面をクリック/タップ(プレビューは置ければ緑、置けなければ赤)。キーなら Q / E(向きは F で切替) |
| タイヤ選択 | タイヤ付近をクリック/タップ |
| ジャッキ | ジャッキボタンを押してタイヤをクリック/タップ(キー J でも可) |
| スコップ | スコップボタンで選び、雪をクリック/タップ(キー C は選択タイヤの向き指定で掘る) |
| 回収 | Backspace |
| ジャッキ | J 設置・撤去、Z 上げ、X 下げ |
| ロープ + 軽トラ | R 接続・解除、G 長押しで引いてもらう |
| VSA 切替 | V |
| ミュート | M |
| リセット | Esc |

### 道具のルール

- スノーヘルパーは、**浮いている(接地していない)タイヤの真下**にしか挟めません。ジャッキで持ち上げてから挟みます。タイヤの前後・斜め・内側(進路)には、接地していても置けます。
- フロアマットは、**浮いているかどうかに関わらず、タイヤの真下には敷けません**。進路には置けます。
- ジャッキの下敷き(沈み込み防止)には、ジャッキの根元から約0.5m以内の道具が使えます。
- **回収**(Backspace / 回収ボタン): タイヤが乗っている道具、上に別の道具が重なっている道具は抜けません。タイヤを浮かせるか動かしてから回収します。抜けるものがあれば、最後に置いたものから回収します。
- 道具が届くのはタイヤから約2.4mまでです。

タッチ端末では画面に運転用のボタン(ハンドル、前進、後退、ブレーキ)が出ます。

難易度は画面下の「標準 / 高難度 / 鬼」で切り替えられます(既定は高難度)。

## 仕組み

- 車両は cannon-es のレイキャスト車両。車重 1,000kg、トレッド 1,295mm、ホイールベース 2,520mm、最低地上高 145mm、4WD。
- タイヤは真下の路面の摩擦で駆動力が決まります(ぬかるみ / 草地 / アスファルト / スノーヘルパー / フロアマット)。
- デフは弱いほうの輪が車軸全体を制限します(トルクバイアスあり)。浮いたタイヤにはトルクが乗りません。
- 泥で空転するとタイヤが掘れて沈み、グリップが落ちます。
- VSA が空転を検知すると出力をカットします。切るかどうかの判断がポイントです。
- 音はすべて Web Audio でリアルタイムに合成しています(音声ファイルなし)。

## ローカルで動かす

```
npm start        # http://localhost:8080
npm test         # ヘッドレスの物理テスト(要 npm install)
```

`vendor/` に three と cannon-es を同梱しているので、静的ホスティング(GitHub Pages など)でそのまま動きます。

## 既知の制約

- 実車のスペックは販売サイトの値で、ホンダ公式の諸元表では確認できていません。
- 前後重量配分と 4WD カップリングの配分比は仮定です。
- 地面そのものの変形(わだち、土の盛り上がり)は未実装です。タイヤごとの「掘れ」の数値のみ。冬道の雪の変形は、スコップで掘る区画の高さだけです(盛り上げる、固める、は無し)。
- 冬道の路面の摩擦係数(圧雪路0.42、吹きだまり0.13〜0.17など)は、ゲーム用に決めた値で、実測値ではありません。
- 難易度バランスは、スクリプトによる操作の検証であり、人が遊んだ検証は十分ではありません。
